# excel_to_tad v16 — кроссплатформенный терминальный выбор

Конвертер `.xlsx`, `.xlsm` и `.xlsb` в типизированные Parquet-файлы для Tad.

Графические библиотеки не используются. Выбор файла и папки выполняется прямо
в терминале и одинаково работает на macOS, Windows и Linux.

## Установка

```bash
python3 -m pip install -r requirements.txt
```

## Простой запуск

Запустите скрипт без путей:

```bash
python3 excel_to_tad.py
```

Появится список папок и Excel-файлов. Управление:

- введите номер — открыть папку или выбрать файл;
- `..` — перейти на уровень выше;
- `~` — перейти в домашнюю папку;
- вставьте полный путь — перейти сразу к нему;
- `q` — отменить;
- при выборе папки результата нажмите `Enter` или введите `.` — выбрать текущую папку.

## Быстрый запуск двойным щелчком

### macOS

Запустите:

```text
run_cli.command
```

Для совместимости оставлен `run_gui.command`, но теперь он тоже запускает
стабильный терминальный выбор без GUI.

### Windows

Запустите:

```text
run_cli.bat
```

### Linux

Запустите из терминала:

```bash
./run_cli.sh
```

## Запуск с готовыми путями

Прежний режим сохранён:

```bash
python3 excel_to_tad.py "/путь/к/файлу.xlsb" "/папка/результата" --overwrite
```

Можно принудительно открыть терминальный выбор:

```bash
python3 excel_to_tad.py --interactive --overwrite
```

Старый аргумент `--gui` временно сохранён для совместимости и теперь включает
терминальный выбор, а не графические окна.

## Правила данных

- числовые показатели сохраняются как `Float64` без фиксированного округления;
- микроскопические хвосты формульного шума (`80.810000000001`) очищаются адаптивно;
- номера, коды и этапы сохраняются как текст без искусственного `.0`;
- смешанные колонки сохраняются как текст;
- точки/тире в числовых колонках становятся `NULL`, а служебные пустые строки удаляются;
- явные `TRUE/FALSE` преобразуются в Boolean;
- `0/1` становятся Boolean только в явно логических колонках;
- временные CSV не создаются, если не указан `--keep-csv`.


## Проверка правильной версии

При запуске первой строкой должно отображаться:

```text
Excel → Parquet/Tad — версия 16
```

Также можно выполнить:

```bash
python3 excel_to_tad.py --version
```

Ожидаемый ответ: `excel-to-tad 16`. В созданном `manifest.json` поле
`converter_version` также должно быть равно `16`. Если там указано `14` или
`15`, запущена старая распакованная папка.

В версии 16 номерные колонки проходят дополнительную проверку непосредственно
перед записью и после записи схемы Parquet. Файл не будет сохранён, если
`No п/п`, номер, код или этап записались числовым типом либо содержат значения
вида `1.0`.
