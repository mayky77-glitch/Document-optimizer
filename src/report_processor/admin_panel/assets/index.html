Шаг 1 · документы

Какие документы проверить?

Добавьте исходные книги и один отчёт, с которым их нужно сравнить.

Этап для проверки В отчёте найдено несколько этапов. Выберите один и повторите проверку с теми же файлами.

Оригиналы не изменяются: проверка работает только с приватными локальными копиями.
