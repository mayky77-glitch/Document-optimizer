# Статус проекта

## Блок 1

- **Номер:** 1
- **Название:** Каркас проекта и инвентаризация источников
- **Статус:** реализован, локальные тесты пройдены; GitHub CI проверяется в PR
- **Вход:** путь к каталогу, обычному файлу или ZIP-архиву
- **Выход:** `FileManifest` и атомарный UTF-8 JSON
- **Версия схемы:** `1.0`

## Публичный API

- `classify_file_by_name(filename)`
- `scan_directory(directory_path, recursive=True)`
- `scan_zip_archive(archive_path, ...)`
- `build_file_manifest(source_path, recursive=True)`
- `save_manifest_json(manifest, output_path)`
- `load_manifest_json(input_path)`
- `FileClassification`
- `FileManifestEntry`
- `ManifestSummary`
- `FileManifest`
- `StatusCode`

## Тесты

Покрыты:

- классификация и комбинированные маркеры;
- временные файлы, копии и устаревшие версии;
- рекурсивный и нерекурсивный обход;
- символические ссылки и детерминированный порядок;
- ZIP Slip, повреждённый ZIP, размер и коэффициент сжатия;
- отсутствие распаковки;
- восстановление UTF-8 имён ZIP без UTF-8-флага;
- дубли;
- атомарная запись;
- сериализация и десериализация;
- публичный контракт источника с `FileManifest`;
- CLI-сценарий ZIP → манифест.

## Результат на реальных данных

Проверен пользовательский ZIP размером 238 633 974 байта без распаковки:

- 177 файловых записей;
- 46 Excel/ODS-файлов (`.xlsx` и `.xlsb`);
- 124 PDF;
- 24 временные или macOS-служебные записи;
- 3 вероятные копии;
- 0 опасных путей;
- 0 нечитаемых записей;
- SHA-256 до и после обработки совпал.

Реальные данные были предоставлены отдельно от пустого центрального
репозитория и не добавлены в Git. Детальная статистика фиксируется в описании
Pull Request.

## Ограничения

- содержимое Excel и PDF не читается;
- листы и строки не обрабатываются;
- индексы документов ещё не нормализуются;
- исходные файлы не изменяются;
- ZIP не распаковывается;
- вычисления и сопоставление работ отсутствуют.

## Зависимость следующего блока

Следующий блок должен принимать готовый `FileManifest`, сохранять `file_id` и
provenance и не выполнять повторную инвентаризацию.
