# Статус проекта

## Блок 1

- **Номер:** 1
- **Название:** Каркас проекта и инвентаризация источников
- **Статус:** реализован, локальные тесты пройдены; GitHub CI проверяется в PR
- **Вход:** путь к каталогу, обычному файлу или ZIP-архиву
- **Выход:** `FileManifest` и атомарный UTF-8 JSON
- **Версия схемы:** `1.0`

## Тесты

Покрыты:

- классификация и комбинированные маркеры;
- временные файлы, копии и устаревшие версии;
- рекурсивный и нерекурсивный обход;
- символические ссылки и детерминированный порядок;
- ZIP Slip, повреждённый ZIP, размер и коэффициент сжатия;
- отсутствие распаковки;
- восстановление UTF-8 имён ZIP без UTF-8-флага;
- дубли;
- атомарная запись;
- сериализация и десериализация;
- публичный контракт источника с `FileManifest`;
- CLI-сценарий ZIP → манифест.

## Блок 3

- **Номер:** 3
- **Название:** Детерминированный выбор файла-источника
- **Статус:** интегрирован локально; ожидает финального review и публикации
- **Вход:** `FileManifest` и `SourceSelectionRequest`
- **Выход:** `SourceSelectionResult` с выбранным кандидатом, рейтингом,
  отклонениями и объяснением

Блок не открывает Excel и не изменяет исходные документы. Он обогащает копию
манифеста периодом, редакцией и статусами имени, затем применяет фильтры и
детерминированное ранжирование. CLI: `enrich-metadata` и `select-source`.

## Блок 4

- **Номер:** 4
- **Название:** Безопасная материализация и чтение Excel-книги
- **Статус:** интегрирован локально; ожидает финального review и публикации
- **Вход:** выбранный `SourceCandidate` из блока 3
- **Выход:** `MaterializedSource`, `DualWorkbookSession`, метаданные книги и листов

`inspect-workbook` безопасно открывает `.xlsx`/`.xlsm` в двух read-only
представлениях: формулы и сохранённые значения. Для ZIP извлекается только
выбранная запись в изолированную временную область с проверкой пути, размера и
CRC; после закрытия сессии область очищается. Неподдерживаемые `.xls`, `.xlsb`
и `.ods` отклоняются до открытия. JSON выбора теперь включает полную
JSON-совместимую запись источника, поэтому его можно передать в
`inspect-workbook --selection` без повторного сканирования.
