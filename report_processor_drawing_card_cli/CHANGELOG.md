# История изменений

## 0.9.2 — интерактивное решение спорных строк

- добавлены массовое отклонение, одобрение доступных предложений и поштучный review в терминале;
- строка review показывает объект, источник, шифр, работу, единицу, количество, стоимость, категорию и причину;
- решения атомарно сохраняются в JSON-аудит и применяются одним повторным запуском;
- частичная публикация требует явного подтверждения и получает статус `PARTIALLY_READY`;
- предупреждения агрегируются по кодам вместо вывода десятков тысяч повторов;
- `FORMULA_NOT_AVAILABLE_FOR_BACKEND` больше не считается strict-блокером при доступном значении;
- `FORMULA_WITHOUT_CACHED_VALUE` остаётся strict-блокером.

## 0.9.1 — надёжность обновления и публикации карточки

- исправлен OpenXML-патчер точных `Decimal`-значений в режиме `update`, включая styled self-closing ячейки;
- выходной XLSX проходит проверку во временном файле до атомарной публикации;
- усилена проверка структуры XLSX, формул с ошибками, стилей и порядка категорий;
- отклонённые решения ручной проверки теперь явно исключают строку из сопоставления.

## 0.9.0 — исправление метрик, шифров и точности XLSX

- добавлена семантическая проверка физической метрики количества;
- исправлен источник 0907: остаток количества берётся из проверенной физической колонки, стоимость — из общей стоимости;
- добавлено восстановление shared formulas;
- служебные маркеры больше не становятся шифрами;
- добавлена точная XML-сериализация Decimal;
- валидатор отклоняет старые карточки с одинаковыми quantity/cost и float-хвостами;
- путь каталога в терминальном меню автоматически дополняется именем XLSX;
- расширено покрытие до 31 теста.

## 0.8.0

- исправлено формирование пустого `manual_review.xlsx`;
- добавлено пошаговое терминальное меню;
- усилено определение индекса объекта и источников.
